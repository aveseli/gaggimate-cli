I have a new coffee: $ARGUMENTS

Help me get started:

1. Research the coffee (origin, processing, roast level, flavor profile)
2. Suggest starting parameters:
   - Temperature (light=93-96, medium=91-93, dark=88-90)
   - Pressure (standard=9, gentle=7-8)
   - Ratio (1:2 classic, 1:2.5 for light, 1:1.5 for dark)
   - Pre-infusion (longer for light roasts)
3. Check if there's a suitable profile: `gaggimate profiles list`
4. If needed, create a new profile (use `gaggimate-profiles` skill)
5. Set up tracking: suggest grind starting point based on roast
6. Pull the first shot and start the dial-in cycle
